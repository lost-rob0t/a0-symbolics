* Design
- Make the reusable Symbolics smoke probe call the local =/api/health= route and
  validate its JSON object before reporting the Prolog integration result.
- Make the container healthcheck and host-side =scripts verify= call
  =/api/health= explicitly, so both readiness paths exercise the real API.
- Add an opt-in live pytest module controlled by =A0_SYMBOLICS_URL=. The default
  suite remains deterministic and service-free; when configured, connection,
  status, content type, and response-shape failures are test failures.
- Force OpenRouter Responses turns to client-side stateless mode and add a
  regression test proving that local full history is sent instead of generation
  continuation state. This prevents a successful Prolog tool result from being
  followed by repeated identical tool calls.
- Non-goal :: do not make configured external MCP commands part of startup or
  install user-specific MCP servers into the image.
