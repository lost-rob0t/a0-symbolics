# Maintenance DOX

## Purpose

- Own the upstream-replayable distribution model: canonical upstream metadata,
  fork-surface budget, and upstream synchronization tooling.

## Ownership

- `upstream.toml` is the canonical, machine-readable record of the immutable
  upstream Agent Zero base commit and the Symbolics distribution remotes.
- `fork-surface.toml` is generated by `scripts/upstream-sync fork-surface`
  and records the classified fork surface budget. Do not edit by hand.
- `reports/` owns machine and human replay evidence (plan reports, conflict
  reports, range-diffs, fork-surface snapshots). Committed reports are
  durable maintenance records; regenerate instead of editing.
- `resolutions/` owns recorded, reusable conflict-resolution notes for
  recurring upstream conflicts.

## Local Contracts

- The upstream commit is authoritative; never identify the base by a mutable
  branch name.
- `upstream.toml` changes only through `scripts/upstream-sync` during a
  reviewed upstream synchronization.
- Stable runtime self-updates resolve against the `[distribution]` remotes;
  raw upstream Agent Zero is never an update target (enforced in
  `helpers/self_update.py` and the durable updater, tested in
  `tests/test_self_update_policy.py`).
- Release identity is `a0s-<upstream-tag>.<series>`; bump `series` only when
  cutting a new Symbolics release on the same upstream base.

## Work Guidance

- Before merging an upstream sync, run `scripts/upstream-sync verify --repo
  <replay-worktree> --full` and keep the report under
  `reports/prepare-<tag>/`.
- Core patches must stay individually explainable; classification notes live
  in `scripts/upstream-sync` (`CORE_PATCH_NOTES`) and feed
  `fork-surface.toml`.
- Prefer migrating behavior into bundled plugins/extensions over widening the
  core patch surface; `plugins/_a0s_prompts` is the model for prompt deltas.

## Verification

- `pytest tests/test_upstream_sync.py tests/test_self_update_policy.py`.
- `scripts/upstream-sync fork-surface` before and after maintenance changes.
